# anti-slop audit 001 (2026-09-04) - ARKA Presensi frontend

Mode: AFTER (audit only, no changes yet). Target: `frontend/src` (React + AntD Pro).
Direction recorded by Iwan: segar, tidak monoton, enak di mata (dibaca ENERGY 2 / RHYTHM 3 / MOTION 1).
Prioritas: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## Temuan

### HIGH

1. **R-02 (em dash)** - 11 em dash di teks UI, tersebar di 10 file:
   `DashboardPage.jsx:93` ("Lembur Bulanan -" pakai em dash), `ImportUploadPage.jsx` (2x, nilai "Matched" dll), `ImportListPage.jsx`, `SheetReviewPage.jsx`, `SheetDetailPage.jsx`, `CellEditModal.jsx`, `ExportPage.jsx`, `LeaveBalanceBadge.jsx`, `CodeBadge.jsx`, `index.css`.
   Fix: ganti dengan titik dua, koma, atau tanda hubung biasa; "belum diisi" sebaiknya pakai teks (mis. "Belum") bukan karakter dash.

2. **R-27 + R-17 (error state tidak ada, angka menyesatkan saat gagal)** - semua halaman data (Dashboard, Import, Export, Mapping, Period, Comparison, Audit) tidak punya penanganan error dari react-query. Di DashboardPage, query error malah dirender jadi `0` ("Hadir 0", "Absen 0") dan chart kosong: angka palsu saat API/network error, user tidak tahu ada masalah.
   Fix: state error per halaman (apa yang gagal + aksi ulangi), jangan tampilkan 0 saat data tidak ada (tampilkan "Data tidak tersedia" / tombol coba lagi).

### MEDIUM

3. **R-21 (dark mode default)** - `useTheme.jsx`: default `isDark = true` tanpa alasan brand. Presensi adalah tool HR internal yang dipakai siang hari di kantor; default gelap tidak melayani konteks. Toggle light/dark sudah ada dan tersimpan di localStorage (bagus), cukup balik default ke light, atau tulis alasan brand kalau tetap mau dark.
   Catatan R-34: perlu cek visual kedua mode setelah default berubah, terutama warna hardcode di CodeBadge, DAY_TYPE_BG, RuleTracePanel.

4. **R-27 (empty state generik)** - tabel memakai empty text bawaan AntD ("No data") tanpa sebab/aksi lanjut. UI-skill checklist: empty state harus bilang kenapa kosong + satu aksi yang mengisinya (mis. halaman Import: "Belum ada import. Upload file fingerprint untuk mulai").
   Halaman terdampak: ImportList, Export, Mapping, PeriodList, Comparison, Audit.

5. **R-03 (responsif)** - Dashboard pakai `Col span={6}` tetap untuk 4 kartu statistik (di layar kecil jadi 4 kolom sempit), dan halaman Review memuat tabel 30+ kolom tanggal 52px + kolom beku tanpa strategi breakpoint. Perlu `xs`/`sm` prop dan konfirmasi scroll horizontal nyaman.

### LOW

6. **R-14 (hierarki kartu statistik rata)** - 4 kartu Dashboard identik padahal "Absen" adalah metrik yang biasanya paling butuh perhatian HR; data sudah real (R-17 aman), hanya hierarki visualnya rata. Saran: beri penekanan berbeda (mis. kartu Absen dengan aksen) sesuai arah "tidak monoton".

7. **R-20 (identitas tipis)** - `<title>` browser masih "frontend" (html default) dan `logo={false}`; brand "ARKA Presensi" hanya muncul di teks sidebar. Polish kecil: title + favicon sederhana.

8. **Konsistensi bahasa campur** - menu/sidebar & tombol dominan English ("Import", "Upload", "Change Password"), judul halaman & statistik Indonesia ("Dashboard Hari Ini", "Kehadiran 7 Hari Terakhir", "Hadir"). Pilih satu bahasa utama (saran: Indonesia, sesuai user HR) untuk copy antarmuka.

9. **R-31 (alasan keputusan visual tidak tertulis)** - palet memakai token AntD default (#1677ff) dan warna status semantik (hijau/merah/amber/biru). Warna status untuk makna boleh, tapi belum ada satu baris alasan tertulis di DESIGN.md. Saat mulai poles visual, tulis DESIGN.md ringkas (arah: segar, ENERGY 2 / RHYTHM 3 / MOTION 1, palet 2-3 warna inti + 1 aksen) supaya hasil tidak jatuh ke default monoton.

## Catatan bukan temuan (aman)
- Tidak ada ikon AI generik (sparkle/robot/star) - R-04 aman.
- Angka statistik dashboard dari API real, tanpa delta fiktif - R-17/R-38 aman untuk data yang tampil (kecuali saat error, lihat temuan 2).
- Navigasi menu semua mengarah ke route yang ada - R-24 aman.
- Tombol yang ada punya perilaku nyata (Generate, Upload, Refresh, override sel) - R-26 aman.
- Tidak ada teks marketing/buzzword - R-16 aman.
